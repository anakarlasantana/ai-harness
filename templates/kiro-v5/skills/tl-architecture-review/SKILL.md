# Architecture Review

1. Establish current-state evidence before proposing changes.
2. Identify boundaries, dependencies, coupling, failure modes, and constraints.
3. Compare viable options using explicit trade-offs.
4. Recommend the smallest architecture change that satisfies the requirement.
5. Record assumptions, risks, and follow-up decisions.

Output: decision, evidence, trade-offs, risks, recommendation, follow-up.
